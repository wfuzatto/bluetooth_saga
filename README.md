# Bluetooth Saga

Projeto de diagnóstico e integração Bluetooth Low Energy (BLE) para fechaduras Saga Systems.

> Estado: integração em investigação. Nenhum protocolo de abertura foi confirmado para o módulo fotografado (inscrição HB2546). Não envie PINs, credenciais, chaves ou logs sensíveis ao repositório público.

A ferramenta Windows permitirá varredura BLE, identificação de anúncios, inspeção **somente de metadados** GATT e exportação local de diagnóstico. A abertura da fechadura dependerá de SDK/protocolo e credenciais autorizados pela Saga/VSKey.

Consulte a documentação e o código nas próximas alterações do projeto.
